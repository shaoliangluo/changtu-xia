一键截出整页长图

支持整页、当前屏幕或框选。截图与导出都在本地完成，不读取浏览记录，也不注入广告。

下载扩展包 查看安装步骤

当前版本 1.2.1 · Chrome / Edge / Firefox · 约几百 KB

安装只需一分钟

下载 zip 后解压，按浏览器加载本地扩展即可。无需注册、无需后台。

  1. 下载并解压 点上方「下载扩展包」，解压到任意固定文件夹（不要边用边删）。
  2. Chrome / Edge 打开 chrome://extensions 或 edge://extensions，打开「开发者模式」→「加载已解压的扩展程序」→ 选中解压后的文件夹。
  3. Firefox 打开 about:debugging#/runtime/this-firefox →「临时载入附加组件」→ 选择文件夹里的 manifest.json。重启浏览器后需重新加载。
  4. 开始截图 打开任意网页，点工具栏「长图侠」图标，或按 Ctrl+Shift+Y（Mac：Command+Shift+Y）。
